# Business Statistics Analysis

This project presents statistical analyses conducted in R as part of a Business Statistics assessment. The analysis focuses on two applied business and public-health datasets:

1. Cardiovascular Disease prevalence across local authority regions in England
2. Customer satisfaction across furniture retail stores

The project demonstrates data cleaning, exploratory analysis, regression modelling, statistical inference, interaction analysis, and data visualisation using R.

## Project Objectives

### 1. Cardiovascular Disease Analysis

The first analysis investigates whether several area-level factors are associated with the prevalence of Cardiovascular Disease (CVD):

- Overweight prevalence
- Smoking prevalence
- Poverty
- Wellbeing

A multiple linear regression model is used to examine their relationship with CVD prevalence. Model diagnostics and visualisations are also included.

### 2. Customer Satisfaction Analysis

The second analysis examines factors associated with customer satisfaction across furniture retail stores, including:

- Delivery time
- Staff satisfaction
- New product range status
- Socio-economic status (SES)

Particular attention is given to whether the relationship between delivery time and customer satisfaction differs across SES categories through an interaction regression model.
